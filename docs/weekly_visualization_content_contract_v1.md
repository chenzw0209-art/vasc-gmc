# 周报可视化内容契约 V1.0

## 1. 目标

技术执行-agent 只消费可视化字段，不直接消费长文案。

周报页目标结构：

```text
顶部标题
本周销售重点
重点客户 Top10 + 客户对应行业扫盲
本周/下周展会 + 同类客户
```

## 2. 输入

线索输入：

```text
Z:\增长分析中台\线索采集-agent\周度抓取结果\YYYY-Www_客户动态候选.xlsx
```

行研输入：

```text
Z:\增长分析中台\行研洞察-agent\周报供给\YYYY-Www_行业扫盲供给.json
```

## 3. 输出

```text
portal\data\weekly\weekly_leads_content_YYYY_Www.json
```

## 4. 页面字段

### 4.1 本周销售重点

```text
重点关注客户数
本周新增客户信号
商品候选
应用候选
建议入库
重点展会
本周摘要短版
```

### 4.2 重点客户 Top10

只展示：

```text
#
应用/商品名称_展示
归属方_展示
一级行业
二级行业
目标市场/渠道_展示
动态类型
动态日期_展示
动态摘要_短
信源等级
是否建议入库
```

不展示：

```text
建议关注点
主信源链接
证据摘要
复核备注
完整详情
```

### 4.3 行业扫盲

只展示：

```text
行业GMV
YoY增长率
CN品牌GMV占比
Top中国玩家
增长信号_短列表
同类客户_短列表
```

### 4.4 展会窗口

只展示：

```text
展会日期_展示
展会名称_展示
地点_展示
行业标签_展示
信源等级
```

### 4.5 同类客户

只展示：

```text
品牌/企业
国家
主营品类
最近事件_短
事件时间
信源等级
```

## 5. 防挤压降级

页面挤压时，按顺序降级：

1. 重点客户 Top10 降为 Top8。
2. 隐藏归属方列，hover 显示。
3. 隐藏动态类型列，改为摘要内标签。
4. 行业扫盲增长信号从 4 条降为 3 条。
5. 展会每栏从 3 条降为 2 条。

禁止：

```text
缩小字号硬塞
横向滚动主表
把详情字段放进主表
把卡片撑高
三栏小字墙
```

## 6. 验收

1. 1440×900 下主表无横向滚动。
2. 所有主表字段使用展示短字段。
3. 长字段只进详情或 tooltip。
4. 行业扫盲来自行研洞察-agent。
5. 线索事实来自线索采集-agent。
6. 页面不生成事实，只负责展示。
