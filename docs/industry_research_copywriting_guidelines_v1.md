# 行业研究模块文案整理规范 V1.0

## 1. 定位

行业研究模块是增长情报中台里的行业工作台，不是长篇研究报告。

它只回答：

- 这个行业规模多大
- 增长是否值得看
- 中国品牌是否有机会
- 行业结构由哪些三级类目构成
- 主要玩家是谁
- 近期有哪些增长信号
- 为什么这个行业值得进入销售扫盘

## 2. 总原则

行业研究文案应服务数据工作台阅读。

要求：

- 短标题
- 短结论
- 强事实
- 少解释
- 可追溯
- 不写长段落
- 不把完整研究报告塞进卡片

每个模块只承载一种信息：

- KPI：只放数字和短说明
- 核心观点：只放结论和 2-3 条论据
- 表格：只放结构化字段
- 增长信号：只放事实和来源方向
- 行业扫盘：只放摘要，不放长论证

## 3. 禁止出现的内容

行业研究模块不要出现：

- BD
- CRM
- 跟进
- 分配
- 商机状态
- 推荐分
- 机会指数
- 星级
- AI推荐
- 必打
- 强烈推荐
- 暴涨暴跌等夸张词
- 无依据的趋势判断
- 长篇政策或报告原文

建议替换为：

- 规模位置
- 结构观察
- CN品牌位置
- 增长信号
- 证据状态
- 公开来源
- 行业扫盘

## 4. 字数预算

| 字段 | 建议长度 |
|---|---:|
| 一级行业中文名 | ≤ 10 个中文字符 |
| 一级行业简称 | ≤ 12 个英文字符 |
| 二级行业中文名 | ≤ 12 个中文字符 |
| 英文副标题 | ≤ 28 个英文字符 |
| KPI标题 | ≤ 8 个中文字符 |
| KPI辅助说明 | ≤ 14 个中文字符 |
| 核心观点标题 | ≤ 14 个中文字符 |
| 核心观点论据 | 每条 ≤ 28 个中文字符 |
| 表格品牌名 | ≤ 24 个英文字符 / ≤ 16 个中文字符 |
| 三级类目名 | ≤ 18 个中文字符 |
| 增长信号单条 | ≤ 45 个中文字符 |
| 行业事件 | ≤ 45 个中文字符 |
| 来源说明 | ≤ 32 个中文字符 |

## 5. 行业名称

### 一级行业

侧边栏一级行业使用简称。

推荐：

```text
Beauty
3C
FMCG
Health
Life
```

不要写：

```text
Beauty & Personal Care
Health & Household
Consumer Tech 全品类
```

### 二级行业

二级行业只显示中文。

推荐：

```text
面部护理
手机与配件
智能安防
电源/储能/充电
厨房小家电
```

不要在二级行业列表里显示：

```text
Facial Skin Care
Smart Security
Power Station and Charging
```

英文名可以放在页面标题括号中，但不进入侧边栏列表。

## 6. 页面标题

格式：

```text
二级行业中文名（英文名）
```

示例：

```text
面部护理（Facial Skin Care）
手机与配件（Mobile Accessories）
```

标题下方说明：

```text
行业研究 · Amazon 美国站 · 2026-04
```

要求：

- 不写长副标题
- 不写完整市场定义
- 不写研究结论

## 7. KPI 文案

KPI字段建议固定：

```text
GMV
月销售额
品牌数
中国品牌数
中国品牌GMV占比
广告指数
流量依赖度
Top3品牌占比
```

辅助说明要求：

- 只写来源或口径
- 不超过 14 个中文字符
- 不写判断句

推荐：

```text
占Beauty 20.7%
同比 +8.2%
GMV加权
品牌集中度
```

不推荐：

```text
该指标说明行业增长潜力较强，值得重点关注
```

## 8. 核心观点卡

每张观点卡结构：

```text
观点标题
- 论据1
- 论据2
- 论据3
```

要求：

- 标题一行
- 论据最多 3 条
- 每条论据不超过 28 字
- 不写段落
- 不写“建议立即进入”

推荐：

```text
规模位置
- 年GMV $5.14B
- 占Beauty 20.7%
- 品牌数843
```

```text
中国品牌位置
- CN GMV占比3.9%
- 中国品牌181个
- 工具类目更占优
```

不推荐：

```text
该行业整体规模较大，且未来伴随消费者对于护肤意识的提升，预计会持续存在较好的增长机会。
```

## 9. 行业概览 Tab 文案

行业概览用于扫盘，不写长报告。

模块包括：

- 市场规模趋势
- 市场特征
- 海外Top品牌
- 中国Top品牌
- 品牌矩阵
- 三级类目结构
- Top类目品牌
- 增长最快品牌
- 下滑最快品牌
- 季节性趋势
- 行业事件

各模块标题控制在 12 个中文字符以内。

## 10. 市场特征

字段建议：

```text
月销量
产品数
Top10集中度
广告指数
流量依赖度
新品占比
```

要求：

- 数值优先
- 不写解释句
- 不写长判断

## 11. 品牌榜单

字段建议：

```text
品牌
国家
GMV
广告指数
流量依赖度
```

要求：

- 品牌名短
- 国家用短码或短中文
- 数字右对齐
- 不写品牌介绍
- 不写推荐理由

## 12. 品牌矩阵

标签要求：

- 只标注 Top5 品牌
- 其他点不显示文字
- 悬浮展示详情

坐标文案：

```text
X轴：GMV
Y轴：广告指数
```

分类标签：

```text
海外品牌
中国品牌
其他品牌
```

不要写：

```text
高潜客户
重点推荐
机会玩家
```

## 13. 三级类目结构

字段建议：

```text
三级类目
GMV
占比
中国品牌占比
代表品牌
```

要求：

- 三级类目名不超过 18 字
- 代表品牌最多 1 个
- 不写完整类目解释

推荐：

```text
面部皮肤护理产品 | $3.89B | 80.0% | 3.4% | CeraVe
```

## 14. 增长信号

增长信号不是销售动作，不写“跟进”。

字段建议：

```text
信号类型
品牌/类目
事件摘要
来源
证据状态
```

信号类型推荐：

```text
新品发布
渠道扩张
展会
市场报告
行业政策
品牌PR
```

事件摘要要求：

- ≤ 45 个中文字符
- 一句话
- 只写公开事实

推荐：

```text
Medicube发布AGE-R新品，强化美容仪内容承接。
```

不推荐：

```text
该品牌可能是未来值得重点打的客户，建议销售后续尽快安排跟进。
```

## 15. 玩家格局文案

玩家格局用于解释竞争结构。

可以出现：

- 头部品牌
- 中国品牌
- 海外品牌
- 集中度
- 品牌矩阵
- 代表品牌

不要出现：

- 推荐分
- 客户评分
- BD优先级
- 跟进建议
- 商机阶段

## 16. 类目结构文案

类目结构用于说明二级行业内部由哪些三级类目组成。

要求：

- 类目名称短
- 结构占比清楚
- 代表品牌最多 1 个
- 不写长解释

推荐句式：

```text
面部皮肤护理产品贡献主要GMV，眼部护理占比较小但品牌集中。
```

不推荐：

```text
从长期市场教育、消费者偏好、产品功效和品牌营销打法等角度看，该类目仍存在复杂变化。
```

## 17. 行业事件

字段建议：

```text
时间
事件
类型
来源
```

要求：

- 时间前置
- 事件不超过 45 字
- 类型使用短标签
- 不写长新闻正文

推荐：

```text
2026-05-12 | Medicube发布AGE-R新品 | 新品
```

## 18. 来源说明

来源说明只用于追溯，不用于占据主视觉。

推荐：

```text
来源：Statista 2025
来源：品牌官方PR
来源：Amazon底表
```

不推荐：

```text
根据多个公开来源、行业资料、品牌官网以及第三方媒体综合判断，该趋势可能具备一定参考意义。
```

## 19. 推荐输入字段格式

```text
一级行业：Beauty
二级行业：面部护理
英文名：Facial Skin Care
周期：2026-04
GMV：$5.14B
月销售额：$431.2M
品牌数：843
中国品牌数：181
中国品牌GMV占比：3.9%
核心观点标题：规模位置
核心观点论据1：年GMV $5.14B
核心观点论据2：占Beauty 20.7%
核心观点论据3：品牌数843
增长信号：Medicube发布AGE-R新品，强化美容仪内容承接。
来源：品牌官方PR
```

## 20. 质量自检清单

- 一级行业是否使用简称
- 二级行业是否只显示中文
- KPI辅助说明是否短
- 核心观点是否最多 3 条论据
- 表格字段是否都是短字段
- 增长信号是否为公开事实
- 是否没有 BD/CRM/跟进/分配/商机字段
- 是否没有推荐分、机会指数、星级
- 来源说明是否短且可追溯
- 是否没有长段落挤进卡片

## 21. 页面挤压责任规则

行业研究模块允许保留完整分析材料，但工作台首屏只展示高优先级短字段。

内容层负责提供：

```text
KPI短说明
核心观点短论据
榜单短字段
增长信号短句
行业事件短句
来源与证据详情
```

可视化层必须执行：

1. KPI 只放数字和短说明。
2. 核心观点只展示标题和 2-3 条短论据。
3. 长分析、完整来源和证据说明进入详情层。
4. 卡片超出高度时减少展示条数。
5. 表格超出宽度时删除次要列。
6. 禁止缩小字号硬塞。
7. 禁止横向滚动主表。
8. 禁止把多个信息组切成三栏小字墙。

如果在 1440×900 屏幕下出现字段互相挤压、文字大量截断、模块高度撑爆或卡片内小字堆叠，默认判定为可视化层未正确降级展示。

详细规则见：

```text
docs/visualization_overflow_guardrails_v1.md
```
